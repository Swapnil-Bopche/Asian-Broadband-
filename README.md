# Asian Broadband Website

A responsive broadband service website with:

- Fixed header + navbar on scroll
- Desktop hover dropdown menus
- Mobile slide-in navigation panel
- Responsive layout with no horizontal overflow
- Pure HTML, CSS & JavaScript (no frameworks)

## Features
- Sticky header & navbar after banner
- Mobile hamburger menu with transform animations
- Nested dropdowns (desktop & mobile)
- Clean responsive breakpoints

## Tech Stack
- HTML5
- CSS3 (Flexbox, Media Queries)
- Vanilla JavaScript
- Bootstrap
